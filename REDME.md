This repository provides a portion of the raw data used in our study on Quenching Anisotropic Wulff Torque Sustains Isotropic Nucleation for Dendrite-Free Zinc Electrodeposition.

The current release contains partial script for phase field method that support the main results reported in our manuscript.

The corresponding calculation scripts, analysis codes, and workflow examples will be made publicly available in a future update once the full data curation process is completed.
